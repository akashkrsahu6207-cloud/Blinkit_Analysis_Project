# Blinkit Sales Analysis Dashboard

An interactive business intelligence dashboard built using Power BI to analyze sales performance, customer behavior, outlet performance, and product trends.

---

## Project Overview

This project focuses on analyzing Blinkit sales data and transforming raw business data into meaningful insights using Power BI.

The dashboard helps stakeholders:

✔ Track total sales  
✔ Monitor outlet performance  
✔ Analyze product categories  
✔ Understand customer ratings  
✔ Compare outlet size and location performance

## Business Problem

Retail companies generate huge amounts of sales data every day.

The challenge is:

- Which outlet performs best?
- Which products generate maximum revenue?
- Which location gives better sales?
- How does customer rating impact sales?

This dashboard solves these business questions.
